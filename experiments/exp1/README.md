# 实验一：JSP 应用

本实验完成 JSP 页面提交、请求转发、错误处理和页面包含功能。

## 实验内容

- 在登录页面输入姓名和年龄。
- 通过 `manger_control.jsp` 判断年龄。
- 年龄大于等于 18 岁时转发到欢迎页面。
- 年龄小于 18 岁时转发到禁止访问页面。
- 使用 `errorPage` 和 `isErrorPage` 处理异常。
- 使用 `jsp:include` 引入友情链接公共页面。

## 主要源码

- `src/main/webapp/lab/exp1/login.jsp`
